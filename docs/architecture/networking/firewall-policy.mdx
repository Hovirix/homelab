## Policy Model

Traffic control within the HX Lab environment follows a centralized, zone-based firewall model.

All inter-segment routing and filtering is enforced exclusively at the OpenWRT gateway.

The default security posture is:

> Deny all inter-zone traffic unless explicitly permitted.

---

## Security Zones

| Zone       | VLAN     | Trust Level |
| ---------- | -------- | ----------- |
| Management | VLAN 10  | High        |
| Server     | VLAN 20  | Medium      |
| Client     | VLAN 30  | Low         |
| WAN        | External | Untrusted   |

Each zone is treated as a separate trust boundary.

---

## Allowed Traffic Matrix

| Source               | Destination          | Allowed    | Conditions                       |
| -------------------- | -------------------- | ---------- | -------------------------------- |
| Client (VLAN 30)     | Server (VLAN 20)     | Yes        | HTTP/S to ingress endpoints only |
| Client (VLAN 30)     | Management (VLAN 10) | No         | Explicitly denied                |
| Server (VLAN 20)     | Database (VLAN 20)   | Yes        | Application-level access only    |
| Server (VLAN 20)     | Management (VLAN 10) | No         | Explicitly denied                |
| Management (VLAN 10) | Server (VLAN 20)     | Yes        | Administrative access only       |
| Management (VLAN 10) | Client (VLAN 30)     | Restricted | Diagnostic purposes only         |
| WAN                  | Server               | No         | No inbound port forwarding       |
| WAN                  | Gateway              | Restricted | WireGuard VPN only               |

---

## Ingress Control

External access is restricted to:

- Cloudflare Tunnel (outbound-established connection)
- WireGuard VPN (administrative access only)

No services are directly exposed via inbound NAT or port forwarding.

---

## Stateful Inspection

The firewall performs stateful inspection of TCP and UDP sessions in accordance with:

- **RFC 791** — IPv4 packet semantics
- **RFC 1812** — Router forwarding behavior
- **RFC 9293** — TCP state management
- **RFC 768** — UDP behavior
- **RFC 792** — ICMP message handling

State tracking ensures:

- Return traffic is permitted only for established sessions
- Invalid or malformed packets are dropped
- Unsolicited inbound traffic is rejected

---

## East-West Controls

Lateral communication between VLANs is not permitted without explicit rule definition.

There are:

- No peer-to-peer cross-VLAN paths
- No distributed routing instances
- No internal bypass around the enforcement point

All cross-zone traffic transits OpenWRT.

---

## Administrative Access

Administrative access to the Management VLAN requires:

- WireGuard VPN authentication
- Identity-based authorization
- Explicit policy allowance

The Management VLAN is isolated from Client networks and considered the highest trust boundary.
