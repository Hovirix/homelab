## Architecture Model

The network architecture is structured around three core layers:

- **Physical Topology** — Connectivity and switching fabric
- **Logical Segmentation** — VLAN-based trust boundaries
- **Policy Enforcement** — Centralized routing, firewalling, and VPN control

Each layer is documented independently to maintain separation of concerns and architectural clarity.

---

## Control Model

All [Layer 3](https://osi-model.com/network-layer/) routing, firewall policy enforcement, and VPN termination are handled exclusively by the OpenWRT gateway.

All [Layer 2](https://osi-model.com/data-link-layer/) connectivity is provided by a managed switch acting as the central switching fabric.

No internal system performs independent routing or bypasses the primary control plane.

---

## Design Objectives

The architecture separates physical topology from logical segmentation in order to:

- Enforce isolation between trust zones
- Eliminate implicit east-west trust
- Reduce public exposure
- Centralize policy enforcement
- Enable comprehensive monitoring
