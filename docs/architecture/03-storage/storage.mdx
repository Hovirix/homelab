## Storage layout

Each Proxmox node uses local ZFS storage.

- `infra-01` → SSD (ZFS)
- `compute-01` → SSD + NVMe (ZFS)

No shared storage between nodes.

---

## Data types

- VM disks
- Application data
- Backups

Data is stored locally on each node.

---

## Backup model

- Backups are performed from Proxmox workloads
- Stored separately from primary data (e.g. PBS)

No replication between nodes.

---

## Retention

- Daily backups
- Short retention window

---

## Constraints

- Storage is node-local
- No live migration
- Failover requires restore from backup
