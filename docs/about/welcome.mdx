## Purpose

HX Lab is a privacy-focused, self-hosted infrastructure platform designed to securely operate sensitive services, test applications in controlled environments, and conduct cybersecurity experimentation.

It is engineered using Infrastructure as Code and immutable systems to ensure reproducibility, security, and operational discipline.
